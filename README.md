# 감정 오리 — 라즈봇2 감정교류 로봇 앱

Hugging Face(Pollen Robotics)의 오픈소스 로봇 **Microduck**에서 아이디어를 빌려,
라즈봇2를 **다마고치처럼 키우는** 감정교류 앱입니다. 휴대폰이나 PC 브라우저로 엽니다.

## 라즈봇2에 설치하기

라즈봇2 터미널(또는 노트북에서 SSH 접속)에서:

```bash
git clone https://github.com/DIDIDIP/emotion-duck.git
cd emotion-duck
bash install.sh
```

- 필요한 패키지(OpenCV)를 확인해 설치하고, **로봇을 켜면 자동으로 앱이 실행**되게 등록해요.
- 끝나면 나오는 `http://192.168.x.x:8000` 주소를 휴대폰·PC 브라우저에서 열면 돼요 (같은 와이파이).
- 업데이트: `git pull && sudo systemctl restart emotion-duck`
- 자동 실행 없이 한 번만: `bash install.sh --no-service` · 바퀴 끄고 시연: `EXTRA="--no-drive" bash install.sh`
- 로봇이 켜질 때 자동 실행되는 Yahboom 기본 프로그램이 카메라를 쓰고 있으면 카메라 기능이 안 될 수 있어요. 그 프로그램을 먼저 끄세요.
- 노트북에서 화면만 시험할 때: `python server.py` (흉내 모드)

## 화면 구성

위쪽 탭으로 **🐣 돌보기 · 🎮 놀이 · 🗺️ 방 지도**를 오갑니다. 위쪽에는 레벨 배지(경험치 링), 이름(눌러서 바꾸기), 🔊 효과음, 📶 기기 연결 버튼이 있습니다.

### 🐣 돌보기

- **LED 얼굴**: 검은 화면에 점으로 그린 눈. 사랑(하트)·신남·기분 좋음·보통·슬픔·속상·놀람·졸림·쿨쿨·피곤·냠냠 표정이 있고, 가끔 깜빡이고 두리번거립니다. **얼굴을 누르면 쓰다듬기.**
- **말풍선**: 로봇이 하는 말 (말소리 듣기를 켜면 소리로도)
- **상태 바**: 행복 · 에너지 · 경험치
- **행동 버튼 4개**

| 버튼 | 하는 일 | 조건 |
| --- | --- | --- |
| 🍪 간식 주기 | 행복 +15, 에너지 +10 | 하루 3번 |
| 🌙 재우기 / ☀️ 깨우기 | 자는 동안 2초마다 에너지 +1, 다 차면 스스로 깸 | |
| ✊ 가위바위보 | 앱 버튼 또는 **카메라 손짓**으로 승부. 이기면 로봇이 신나고 지면 아쉬워함 | **Lv5에 열림**, 에너지 15 이상 |
| 🏠 이리 와 | 등록한 집 표시로 찾아옴 | **Lv7에 열림**, 에너지 15 이상, 집 등록 필요 |

- **📷 카메라 화면**(접기): 로봇 카메라, 집 등록, 마지막으로 알아본 손짓
- **📈 기분 기록**(접기): 최근 5분 기분 그래프와 최근 일
- **📶 버튼**(오른쪽 위): 기기 연결 — QR 코드, 응답 속도, 다른 로봇 주소

### 🎨 꾸미기 (레벨업 선물)

레벨이 오르면 축하 화면에 **🎁 선물 상자**가 나타나요. 눌러서 열면 새 아이템이 나오고 **바로 착용**하거나 **옷장 보기**로 고를 수 있어요.
위쪽 🎨 버튼이 옷장이에요 (새 아이템이 있으면 빨간 점, 아이템에 NEW 표시).

| 종류 | 아이템 (열리는 레벨) |
| --- | --- |
| 💡 화면 빛 | 하얀 빛(1) · 민트(2) · 분홍(3) · 햇살(6) · 🌈 무지개(10) |
| 🎨 몸 색 | 차콜(1) · 크림(2) · 하늘(4) · 딸기(5) · 황금(9) |
| 🎀 머리 장식 | 없음 · 리본(2) · 모자(3) · 꽃핀(4) · 헤드폰(5) · 왕관(8) |
| ✨ 볼 | 없음 · 발그레(3, 볼에 분홍 점) · 반짝반짝(7, 화면 모서리 별) |
| 🖼️ 배경 | 기본 · 벚꽃(4) · 밤하늘(6) · 바다(8) |

- 고른 모습은 로봇(`pet.json`)에 저장돼서 휴대폰·PC 어디서 열어도 같아요.
- 아이템을 더하려면 `game.py`의 `ITEMS`에 한 줄, 모양은 `web/closet.js`에 색·이모지 한 줄을 넣으면 돼요.
- 발표 때 빨리 보여 주려면 `python3 server.py --boost 5` (경험치 5배).

### 🎮 놀이 (호감도 올리기)

**호감도**(0~100)는 로봇과 얼마나 친한지를 나타내요. 단계: 낯가림 → 아는 사이(15) → 친구(35) → 단짝(55) → 베프(75) → 소울메이트(92).
단계가 오르면 축하하고, 앱을 열 때 하는 첫인사가 단계마다 달라집니다("어… 안녕?" → "보고 싶었어! 💕").

화면 속 게임이 아니라 **라즈봇이 몸으로 직접 하는 놀이**예요. 앱은 리모컨·점수판 역할만 해요.

| 놀이 | 로봇이 하는 일 | 사람이 하는 일 | 점수 |
| --- | --- | --- | --- |
| 🌸 무궁화 꽃이 피었습니다 | 술래. 고개(짐벌)를 옆으로 돌리고 부저로 10박자 노래 → 돌아보며 **카메라로 움직임 감지** → 들키면 "잡았다!" | 노래하는 동안 다가가고, 돌아보면 멈추기. 로봇 바로 앞 15cm(**초음파**)까지 오면 승리 | 승리 9~10, 잡히면 버틴 횟수×2 |
| 🕺 따라 춤추기 | **바퀴·고개·불빛·부저**로 춤 동작(왼쪽·오른쪽·앞·뒤·끄덕)을 차례로 보여 줌. 맞히면 그 동작을 따라 춤 | 같은 순서로 앱 방향 버튼(또는 손짓) 누르기. 한 판마다 하나씩 길어짐 | 성공한 판 수 (최대 8) |
| ⚽ 공 찾아오기 | 등록한 색 공을 **카메라로 찾으며** 빙글 돌다가, 찾으면 방향을 맞춰 공 앞까지 감 | 처음에 공 색 등록, 시작하면 3초 안에 공 굴리기 | 10초 안 10점, 늦을수록 감점 |

- 무궁화: 초음파 센서가 없거나 안 읽히면 앱의 **🖐 터치!** 버튼으로 대신해요. 움직임 민감도는 `robotgames.py`의 `MOTION_RATIO`(기본 2.5%).
- 따라 춤추기: 실제 로봇일 때는 앱에 동작을 보여 주지 않아요(로봇을 보고 외워야 해요). 노트북 흉내 모드에서만 아이콘으로 보여 줘요.
  손짓 인식 코드에서 `gesture`로 `left`·`right`·`forward`·`back`·`nod`(또는 `point_left`·`thumbs_up` 등)를 보내면 버튼 대신 손짓으로 할 수 있어요.
- 공 찾아오기: '이리 와'의 색 추적을 공에 그대로 써요 (`ball.json`에 공 색 저장).
- 점수 비율에 따라 **호감도 +1~6**, 행복·경험치도 오르고 에너지 5를 씁니다. 놀이 중에는 다른 이동(방 지도·이리 와)을 막아요.
- 게임마다 **하루 3번**까지 호감도 보상. 그 뒤로는 연습(보상 없음).
- 그 밖에 호감도가 오르는 일: 가위바위보 한 판 +1, 그날 첫 방문 +2.

### 🗺️ 방 지도

1. 로봇을 방 가운데쯤 두고 **🔍 방 스캔하기** → 로봇이 30°씩 한 바퀴 돌며 사진 12장과 벽까지 거리를 잽니다 (약 20초).
2. **위에서 본 지도**가 생깁니다: 초록 = 갈 수 있는 곳, 검은 선 = 벽·물건, 파란 아이콘 = 로봇.
3. **지도를 누르거나, 아래 사진 띠에서 바닥을 누르면** 목표 핀이 꽂히고 "왼쪽으로 30° 돌아 1.2m"처럼 알려 줍니다. 벽 너머를 누르면 벽 앞까지로 줄여 줍니다.
4. **🚗 여기로 와!** → 돌아서 그 거리만큼 갑니다. 가는 중 초음파에 18cm 안쪽 장애물이 잡히면 멈춥니다.

어떻게 정확도를 맞추나
- 라즈봇2에는 바퀴 회전 센서가 없어서, **회전 각도는 카메라 사진으로 잽니다**: 앞뒤 사진의 특징점(ORB)이 옆으로 밀린 정도 → 실제로 돈 각도. 스캔하면서 회전 속도를 스스로 보정하고, 이동할 때도 그 방향에서 찍었던 사진과 지금 화면을 비교해 방향을 최대 3번 고칩니다.
- **직진 거리는 시간으로 계산**합니다. `roommap.py`의 `CM_PER_SEC`를 실제로 재서 맞추세요: 로봇을 3초 직진시키고 간 거리를 줄자로 재서 3으로 나눈 값.
- 사진 속 바닥을 누를 때 거리는 카메라 높이(`CAM_HEIGHT`)와 숙인 각도(`CAM_TILT_DOWN`)로 계산합니다. 실제 키트에 맞게 재서 넣으세요.
- 무늬가 거의 없는 흰 벽만 보이면 사진 비교가 안 되어 시간 계산으로 돌아갑니다.
- 노트북(흉내 모드)에서는 가로 4m × 세로 3m 가상의 방(소파·책상·화분)으로 스캔과 이동을 흉내 냅니다.

## 키우기 규칙

- 행동을 하면 경험치가 쌓이고 레벨이 오릅니다(레벨 n → n+1 에 20×n 필요). 레벨이 오르면 축하 화면이 뜨고 새 기능이 열립니다.
- 행복은 90초마다 1씩 줄고, 30 아래로 떨어지면 로봇이 "심심해… 놀아 줘" 하고 칭얼댑니다.
- 에너지는 놀면 줄고 재우면 찹니다. 15 아래면 놀자고 해도 "너무 졸려… 재워 줘"라며 거절합니다.
- 방 스캔은 에너지 10, 지도 이동은 에너지 8을 씁니다 (경험치 +15, +10).
- 진행 상황은 `pet.json`에 저장됩니다. 처음부터 다시 키우려면 이 파일을 지우세요.
- 발표 시연처럼 빨리 레벨을 올려야 하면 `python3 server.py --boost 5` (경험치 5배).
- 숫자는 `game.py` 맨 위에서 바꿀 수 있습니다.

## 손짓 인식 코드와 연결

팀에서 만든 MediaPipe 손짓 인식 결과를 그대로 보내면 됩니다.

```python
import json, urllib.request
def send_gesture(name):   # rock, scissors, paper, wave, thumbs_up, palm
    body = json.dumps({"jsonrpc": "2.0", "id": 1, "method": "gesture", "params": {"name": name}}).encode()
    urllib.request.urlopen(urllib.request.Request("http://127.0.0.1:8000/rpc", body, {"Content-Type": "application/json"}))
```

가위바위보 버튼을 누른 뒤 10초 안에 `rock`/`scissors`/`paper`가 오면 그 손으로 승부합니다. 그 밖의 때 `wave`·`thumbs_up`은 인사·칭찬으로 받아 행복과 경험치가 오릅니다.

## 실행 (라즈봇2에서)

```bash
cd emotion-duck
python3 server.py              # 바퀴까지 사용
python3 server.py --no-drive   # 책상 위 시연: 고개·불빛·소리만
python3 server.py --camera 1   # 카메라가 /dev/video1 일 때
python3 server.py --boost 5    # 발표 시연용: 경험치 5배
```

화면에 나오는 `http://192.168.x.x:8000` 주소를 PC 브라우저에서 열고, 오른쪽 위 **📶 버튼**의 QR을 휴대폰으로 찍으면 됩니다.
휴대폰과 로봇은 같은 와이파이에 있어야 합니다.

- 설치할 것: 집 찾기에는 OpenCV가 필요합니다(`sudo apt install python3-opencv`, 라즈봇2 이미지에는 보통 들어 있음). 나머지는 파이썬 표준 라이브러리만 씁니다.
- QR 그림은 인터넷에서 작은 라이브러리를 받아 그립니다. 인터넷이 없으면 주소 글자를 직접 입력하세요.
- 노트북에서 실행하면 라즈봇 라이브러리가 없어 바퀴·고개·불빛은 "흉내 모드"(콘솔 출력)로, 집 찾기는 노트북 웹캠으로 동작합니다.
- 윈도우 PC에서 실행하고 휴대폰으로 접속이 안 되면, 방화벽에서 파이썬의 "개인 네트워크" 접근을 허용하세요.

## 이리 와(집 찾기) 사용법

1. 빨강·파랑처럼 **진한 색 물건**(상자, 색종이)을 집 자리에 둡니다.
2. **📷 카메라 화면**을 열고 **가운데 네모**에 그 물건이 보이게 한 뒤 **"이걸 집으로 등록"**을 누릅니다. 색이 `home.json`에 저장되어 껐다 켜도 기억합니다.
3. 로봇을 다른 곳에 두고 **👋 이리 와**를 누르면:
   제자리에서 조금씩 돌며 찾기 → 찾으면 화면 가운데로 맞추며 앞으로 → 집 표시가 화면 폭의 45%만큼 커지면 도착.
4. 오리의 기분도 함께 움직입니다: 찾는 중 두리번, 찾으면 신남, 도착하면 편안, 못 찾으면 속상.

잘 안 될 때 `home.py` 맨 위 숫자를 조정합니다.

| 증상 | 고칠 값 |
| --- | --- |
| 집 반대쪽으로 돈다 / 다가가며 점점 벗어난다 | 모터 배선 방향이 반대인 것. `robot.py`의 `_motors`에서 왼쪽·오른쪽을 바꾸기 |
| 너무 멀리서 멈춘다 / 부딪힌다 | `ARRIVE_WIDTH` (작게 하면 멀리서 멈춤) |
| 비슷한 색 다른 물건으로 간다 | 더 드문 색의 집 표시 쓰기, `MIN_AREA` 키우기 |
| 찾다가 너무 빨리 포기한다 | `MAX_PULSES` 키우기 |

## 감정이 움직이는 방식

- 기분은 **기분(좋음↔싫음)** 과 **활기(흥분↔졸림)** 두 숫자(-100~+100)로, 여기에 **친밀도(0~100)** 를 더합니다.
- 사건이 오면 숫자가 바뀌고 가장 가까운 감정(신남·편안·놀람·속상·슬픔·졸림·보통)이 오리 표정이 됩니다.
- 시간이 지나면 감정은 천천히 가라앉고(반감기 20초), 1분 동안 아무 일이 없으면 심심해하다 3분 뒤 잠듭니다.

## 다른 코드와 연결 (골·홈런 감지, 손짓 인식)

앱 버튼에서는 뺐지만, 이미 만든 감지 코드는 그대로 연결할 수 있습니다.

```python
from duck_client import tell_duck
tell_duck("goal")        # 또는 "homerun", "wave", "mood:sad" ...
```

감지 코드가 노트북에서 돌면 `tell_duck("goal", url="http://<라즈봇 IP>:8000/rpc")`. 사건 목록은 `emotion.py`의 `EVENTS`에 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `server.py` | 연결: JSON-RPC(`POST /rpc`), 실시간 전송(`/stream`), 카메라 화면(`/camera.jpg`) |
| `emotion.py` | 마음: 사건 → 기분 계산, 시간에 따른 변화 |
| `robot.py` | 몸: 라즈봇2 바퀴·고개·불빛·부저, 감정별 반응 동작 |

## 확인이 필요한 것

- 초음파 읽기(`robot.py`의 `distance_cm`: `Ctrl_Ulatist_Switch`, 레지스터 0x1b/0x1a)도 Yahboom 예제 기준입니다. 값이 안 나오면 지도는 모든 방향을 '트인 곳'으로 그리고, 이동 중 장애물 멈춤이 동작하지 않습니다.
- `robot.py`의 `Ctrl_Car`, `Ctrl_Servo`, `Ctrl_WQ2812_brightness_ALL`, `Ctrl_BEEP_Switch`는 Yahboom Raspbot V2 공식 예제 기준 이름입니다. 키트 버전에 따라 다르면 이 네 곳만 고치면 됩니다.
- 집 찾기는 가짜 카메라 영상으로 네 방향(0°, 30°, -90°, 120°)에서 도착까지 시험했습니다. 실제 바닥·조명에서는 위 표의 값을 조정해야 할 수 있습니다.
